# WaiGame

> 因热爱相聚，为好玩而来。

WaiGame 是由一群来自中国、热爱 Minecraft 的玩家共同创建的小游戏群组服。

从起床战争、街机游戏，到我们自创的 5V5 传奇对决，再到仙境生存，我们希望和更多喜欢 Minecraft 的朋友一起，分享游戏的快乐，留下属于彼此的回忆。

## 在 WaiGame 玩什么？

### 小游戏

- **起床战争**
- **街机游戏**
- **传奇对决** — WaiGame 自创的 **5V5** 玩法。

### 生存

- **仙境生存**
